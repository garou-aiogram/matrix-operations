# Операции над матрицами — Windows-приложение

Курсовая работа (C++): настольное приложение для Windows, выполняющее основные операции линейной алгебры над матрицами.

## Возможности

| Операция | Статус |
|---|---|
| Сложение и вычитание | ✅ ядро |
| Умножение матриц и на число | ✅ ядро |
| Транспонирование | ✅ ядро |
| Определитель (метод Гаусса с выбором главного элемента) | ✅ ядро |
| Обратная матрица (метод Гаусса–Жордана) | ✅ ядро |
| Оконный интерфейс: ввод матриц, выбор операции, вывод результата | 🚧 в разработке |
| Сохранение и загрузка матриц из файла | 🚧 планируется |

## Структура

```
src/
  Matrix.h / Matrix.cpp   — класс Matrix и алгоритмы
  main.cpp                — консольная проверка ядра (временно)
CMakeLists.txt
```

## Сборка

```bash
cmake -S . -B build
cmake --build build
./build/matrix_demo        # Windows: build\Debug\matrix_demo.exe
```

## Обработка ошибок

Несовместимые размеры, выход за границы и вырожденная матрица (при обращении) приводят к исключениям `std::invalid_argument`, `std::out_of_range` и `std::domain_error`, которые интерфейс показывает пользователю.
